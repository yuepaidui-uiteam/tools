安装说明（3 步）

先下载工具，再安装运行环境，最后启动即可。

都是免费步骤，不需要手动配置 PATH。

  1. 下载并解压工具

    下载 B 站下载器，解压后打开文件夹即可；压缩包只包含本工具运行所需文件。

  2. 一键安装 Python 和 FFmpeg

    打开 Windows PowerShell，点下面按钮复制命令，粘贴后按回车。确认安装即可；无需手动找文件夹或修改 PATH。

    winget install 9NQ7512CXL7T -e; winget install --id Gyan.FFmpeg.Essentials -e
    如果提示找不到 winget

    使用 Python 官方安装页和 FFmpeg 下载页手动安装；FFmpeg 解压后还需把含 ffmpeg.exe 的 bin 文件夹加入 Windows Path。

  3. 启动并下载视频

    双击 run.bat 并保持黑色命令窗口打开，然后回到本页刷新。在上方下载框粘贴单个 B 站视频链接，点“下载视频”；完成后点“保存视频”。

目前支持公开可访问的单个视频链接；不支持合集或分 P 选择。请遵守平台规则与版权要求，只保存你有权保存的内容。
