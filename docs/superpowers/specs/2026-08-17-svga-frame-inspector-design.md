# SVGA 组帧查看与上传区样式设计

## 目标

在现有 `svga-preview.html` 中增加逐帧查看能力，并将 SVGA 上传框调整为与图片工具一致的纯深紫色面板布局。

## 设计

- 上传框继续位于棋盘预览区中央，使用不透明深紫色背景、紫色虚线边框和现有渐变按钮；未载入动画时隐藏底层空状态文字，避免重叠。
- 预览区下方增加紧凑控制条：播放、暂停、上一帧、下一帧、当前帧/总帧数、帧进度滑块和 `1x` 速度标识。
- 加载 SVGA 后用动画总帧数初始化滑块；播放器 `process` 事件同步当前帧。拖动滑块或点击上一帧/下一帧时调用 `stepToFrame(frame, false)`，保持暂停查看单帧；播放按钮调用 `start()`，暂停按钮调用 `pause()`。
- 未加载文件时控制条禁用；解析失败时保留上传框并清空/禁用逐帧控制。

## 验证

- 用静态检查确认新控件、事件绑定和成功/失败状态切换均存在。
- 用 `git diff --check` 检查空白错误。
- 在本地页面加载 SVGA 后确认控制条能显示帧数，拖动和前后帧按钮能改变画面。
