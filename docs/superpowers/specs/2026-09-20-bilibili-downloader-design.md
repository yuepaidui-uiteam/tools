# Bilibili 本机视频下载工具设计

## 目标

新增一个免费、本机使用的 B 站视频下载网页。用户只在网页里粘贴视频链接、查看下载进度并保存结果；解析和下载由本机 Flask 服务调用 yt-dlp 完成，DASH 音视频合并由 FFmpeg 完成。

## 方案与范围

- 独立目录 `bilibili-downloader/`，不改变现有静态工具首页的在线部署方式。
- Flask 页面只监听 `127.0.0.1`，默认通过 `http://127.0.0.1:5000` 使用；不向局域网或公网开放。
- 前端仅提供单条视频下载流程：输入链接、开始任务、显示状态/进度、提供最终文件下载。
- 接受 B 站视频页链接及 `b23.tv` 分享短链；拒绝其他站点、非 HTTP(S) URL、畸形链接和播放列表。
- 使用 yt-dlp 下载无需登录且用户有权保存的视频；不读取、保存或要求用户粘贴 Cookie，不尝试访问会员、付费、区域或其他权限受限内容。
- 初版不做账号登录、任务队列、批量/多 P、字幕/封面、远程部署或跨设备访问。

## 用户流程

1. 用户按说明安装 Python、项目依赖和 FFmpeg，并运行启动命令。
2. 浏览器打开本机地址，粘贴 B 站视频链接并点击“开始下载”。
3. 页面显示任务状态和 yt-dlp 下载进度；成功后显示“下载视频”链接。
4. 文件写入应用自身的 `downloads/` 目录，用户通过浏览器下载到指定位置。
5. 对无效链接、受限内容、网络错误或缺少 FFmpeg，页面显示可读错误，不泄露调试堆栈。

## 组件与接口

- `app.py`：本机 Flask 服务、输入校验、任务状态、yt-dlp 调用及安全文件响应。
- `templates/index.html`：单页中文界面，视觉参考用户提供的深色背景、醒目标题、单行链接框和蓝色主按钮；包含加载、下载中、成功、失败状态。
- `requirements.txt`：记录 Flask 与 yt-dlp 的 Python 依赖；FFmpeg 作为独立系统依赖在运行说明中列出。
- `POST /api/download`：接收 JSON 中的 `url`，校验后创建独立任务，返回任务 ID。
- `GET /api/status/<task_id>`：返回任务状态、进度、错误信息或最终文件标识。
- `GET /downloads/<task_id>`：只发送该任务自己的最终文件，使用安全路径处理及附件下载响应。

## 安全与可靠性

- 使用 `debug=False`，绑定回环地址；服务不得监听 `0.0.0.0`。
- 在启动 yt-dlp 前校验 scheme 与精确主机名，并限制为 Bilibili extractor，避免把本机服务变成任意 URL 下载/SSRF 入口。
- 每个任务使用 UUID 独立工作目录和唯一输出名，不通过扫描下载目录中的“最新文件”推断任务结果。
- 任务状态并发访问需加锁；未知任务 ID 返回 404；文件响应不得接受客户端任意路径。
- 不在页面或日志中保存 Cookie、账户凭据或不必要的完整链接；错误返回面向用户且长度受限。
- 下载完成的文件保留在本机 `downloads/` 中，用户可自行删除；初版不自动删除。

## 验收标准

- 本机启动后页面可打开，窄屏下输入框与按钮仍可操作。
- 有效 B 站链接可创建任务并显示进度；成功后只能下载该任务对应的合并文件。
- 空链接、非 B 站链接、异常 URL、未知任务及下载失败都有清晰错误状态。
- 两个同时运行的任务不会串用进度、目录或下载文件。
- 服务仅绑定本机且调试器关闭；启动与依赖说明可让用户独立运行。
- 使用自动化测试验证链接校验、任务状态与输出映射；使用一个用户有权保存的公开视频完成手动端到端验证（若平台策略或网络限制阻止，则如实记录，不绕过限制）。

## 假设与限制

- 工具面向用户自己的电脑，不作为在线公共服务部署。
- yt-dlp 对 B 站的支持受平台变更、网络、地域与内容权限影响；不能保证任意视频或画质均可下载。
- “免费”指不需要付费解析 API 或云服务器；用户仍需自行安装软件并承担网络流量。
